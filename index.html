数据管理

学习记录、收藏与偏好只保存在这台设备的浏览器里，不会上传。换设备、清理浏览器数据或使用无痕模式会丢失，建议每周导出一次备份。

导入说明：选择此前导出的 JSON 备份文件，将覆盖当前设备上的记录。

内容来源与更新机制

时政要闻：由 scripts/fetch_daily.py 每日自动抓取新华社、人民日报、中国政府网、央视新闻等权威来源，生成 data/日期.js；抓取失败时可人工在 data/manual/日期.json 中补录，保证不断更。
公考常识：来自人工维护的固定题库 data/facts-pool.js，按天自动轮换 10 条，考点不随时间失效，无需联网更新。
更新时点：通过 GitHub Actions 定时任务，每天北京时间 08:00 抓取并发布；页面打开时会自动检查是否有更新。

装到手机上，像 App 一样用

Android / Chrome：打开本页 → 右上角 ⋮ → 「添加到主屏幕」。
iPhone / iPad：必须用 Safari 打开 → 底部「分享」按钮 → 「添加到主屏幕」。（微信内置浏览器不支持）
电脑：Chrome / Edge 地址栏右侧会出现「安装」图标，点击即可独立窗口运行。

危险操作

清空后本机的已读、已背与收藏记录将无法恢复，请务必先导出备份。
